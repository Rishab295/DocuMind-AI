---

## 📌 Overview

**DocuMind AI** is a full-stack AI analytics application built with Python and Streamlit.

The application allows users to upload **PDF, TXT, CSV, and Excel files** and interact with their data through a unified AI-powered workspace.

For structured datasets, the application provides data profiling, statistics, data-quality analysis, interactive visualizations, and AI-generated insights.

For unstructured documents, DocuMind AI uses a **Retrieval-Augmented Generation (RAG)** pipeline to retrieve relevant information from uploaded documents and generate context-aware answers using a Large Language Model.

The project is deployed as a live web application using **Streamlit Community Cloud**.
